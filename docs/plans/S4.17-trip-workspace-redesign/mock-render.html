Workspace screens — mock render

Rendered 1:1 from the two Figma CSS dumps (workspace.txt, add edit activity.txt) for the workspace reconciliation. Every draft trip opens into this workspace. Polls are rendered but parked (no backend yet); the Notes tab exists in the mock but will be omitted in the build.

Platform-forced deviations (everything else is as-mocked)

  • Fonts — Geist / Outfit / Inter can't be fetched inside an artifact (CSP blocks font CDNs); system fallbacks are used at the mock's exact sizes, weights and line-heights. The app itself ships the real faces.
  • Avatars — the mock's avatar fills are AI-image prompt URLs, not assets; rendered as flat placeholder circles at the mocked 16px size, white ring, −6px overlap.
  • Text encoding fixed — the dump's mojibake is restored: "â¢" → "•", "â±PHP" → "₱PHP".
  • Mock oddities (the Estimated Price field's map-pin icon + "Search for a place..." placeholder, the Add screen's second CTA reading "Save Changes", the finalize sheet's #FF6B35/Inter styling) are kept as-mocked — they're queued as reconciliation questions, not silently corrected.
