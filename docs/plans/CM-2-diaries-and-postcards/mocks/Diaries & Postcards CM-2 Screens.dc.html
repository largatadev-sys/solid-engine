Contracts · what the client promises the server
C1Create a diary is two acts
Next: Add Your Days blocks (CTA shows a spinner, fields lock) until the server returns the diary id and its candidate days. No optimistic days: the client never derives a date. On failure the form stays filled, an inline error sits under the CTA ("Couldn't create the diary. Try again."), nothing is created.
On 3, each day card is saved as its own act when the user leaves it (blur / scroll past) with at least one photo. Post submits whatever is unsaved and returns to the profile with the 6 toast. A day with no photos is never sent; it has no row afterwards.
Back from 3 → L4. Discard deletes the diary and any saved days in one act; Keep editing returns with everything intact.
C2Post a postcard
Photos upload as soon as they're picked (per-tile progress ring over the thumbnail, check appears at 100%). Post is disabled until every pick has landed and the caption is non-empty or a place is set. Post sends caption, place and the uploaded ids in one act.
Success: pop the compose stack, land on the profile Diary tab, 7 toast, new card at the top with a 200 ms fade-in. Failure: stay on compose, toast "Couldn't post. Your postcard is still here." Nothing is drafted server-side.
Same rule for D (postcard on a day): success returns to B with the day expanded and the new postcard highlighted for 1 s (#FFF7ED wash fading out).
C3Deletes are confirmed, then optimistic
Kebab → sheet → confirm (L1–L3). The confirm's count comes from the server payload already on screen; the client never recounts. On Delete the row/section exits immediately (M4), the stat decrements, and the request fires.
Failure within the request: the row re-enters in place with a 200 ms fade, the stat restores, and a dark toast reads "Couldn't delete. Try again." No second confirm.
Deleting a diary from B pops back to the profile first, then plays the same exit there. Deleting the last loose postcard leaves the sections as they were; deleting the last of everything shows K1.
C4Add to diary moves, never copies
H1 lists diaries the server returns (most recently updated first); H2 lists that diary's days. The CTA sends postcard id + day id. The client does not check for duplicates or day limits; the server answers.
Success: sheet dismisses (M1 out), the loose card exits from the top of the Diary tab (M4), the target section's postcard list grows by one, toast "Added to Lisbon & the Algarve". Failure: sheet stays open, inline line under the CTA "Couldn't add it. Try again.", nothing moves.
Edits (caption in G1, diary fields in F, day place in E) save on the CTA, not on blur; Back with unsaved changes asks "Discard changes?" with the L4 anatomy.
Motion · timings are the spec
M1Sheets
Scrim fades in 200 ms; sheet slides up 260 ms, cubic-bezier(.2,.8,.2,1). Out: sheet down 200 ms ease-in, scrim fades with it. Tap on scrim, Cancel, or a row all dismiss. Used by 1, 2b, K2/K3, G1, H1/H2. Live in 5.
M2Toasts
Drop in from the top: 220 ms ease, translateY(−12 → 0) + fade. Hold 2000 ms. Out: 180 ms fade + translateY(−8). Success is #D1FAE5/#054D38; failure is #1C1917/#FFF with the same timing. One toast at a time; a new one replaces the current instantly. Live in 6, 7.
M3Confirm dialogs
Scrim 180 ms; dialog scales .96 → 1 with fade, 180 ms ease-out. Out: 140 ms fade. Cancel and scrim tap both dismiss; the destructive button never has a hover state on touch, only the 120 ms press scale. L1–L4; live in 5.
M4Row and section exit / enter
Exit: 220 ms, opacity → 0, translateY(6px), height collapses to 0 (layout animates, siblings slide up). Enter: 200 ms, opacity 0 → 1, scale .92 → 1. Section collapse uses the same enter for the body; the chevron rotates 180° over 200 ms. Live in 5.
M5Selection checks
Check badge pops: scale .5 → 1.12 → 1 over 220 ms, cubic-bezier(.2,.9,.3,1.3). Photo tiles enter with M4's enter. In the calendar, Start/End dots fill in 120 ms and the band fades in 160 ms; chips swap their outline in 160 ms. Live in 2b, 3, H2.
M6Press states
Filled CTAs scale to .98 on press, 120 ms. Round icon buttons scale to .92. Sheet rows and list rows dim to 60% opacity, no scale. Disabled CTAs are #F5C4AE with no press. Everything honours Reduce Motion: durations drop to ~1 ms, positions still change.
