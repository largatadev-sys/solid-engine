Contracts
C1 · FOLLOW STATE MACHINE
States: not_following → pending → following. Tap is optimistic — pill flips to Following immediately, POST fires in background. On failure: revert pill + toast "Couldn't follow @handle". Tap while Following → confirm-free unfollow, same optimistic pattern. Pending taps are ignored (no queue). Follow is idempotent server-side.
C2 · FOLLOW PILL TREATMENT
Follow = filled terracotta (#EA580C bg, #FFF label) — the one primary action on someone else's page. Following = neutral outline (1px #E7E5E4, ink label, leading 14px check) — matches the own-profile Edit pill weight so a followed profile reads calm. Height 40, radius 999, 13.5px/700, press scale 0.96.
C3 · PUBLIC HEADER ANATOMY
Reuses own-profile anatomy: 72×72 avatar (r36, #FDE4CF fallback + #C2410C initials), name 22/800, meta "@handle · #N" 13px muted, bio 13.5px (row omitted when empty — no placeholder). Stats row is two cells only: Published, Postcards. Follower counts are not public. No cogwheel, no Edit anywhere on another traveler's profile.
C4 · PRIVACY SCOPE
Public profile shows published content only: public diary postcards grouped by trip, and published itineraries. Drafts, private trips, and trip workspaces never appear. Viewing your own handle via search routes to your own Profile tab (with Edit), never to this screen.
C5 · PEOPLE SUGGESTIONS
People joins the existing suggestion groups (order: People, Destinations, Itineraries) under the same pipeline: min 2 chars, 300ms debounce, latest-wins. Prefix match on display name or handle, case-insensitive. Cap 3 + "See all people" footer routing to the results screen with the live query. Self is excluded from suggestions.
C6 · PEOPLE RESULTS
Route: /discover/people?q= (addressable, restores on deep link). Cursor pagination, page 20, fetch at 5 rows from end. Row = 44px avatar, name 15/700, handle 13 muted, trailing chevron; tap → public profile (1a). Count line "{n} people" updates with the query. No-results state per 1d variant — never a blank list.
C7 · EMPTY & EDGE STATES
Empty diary: "Nothing published yet" + "When {first name} publishes postcards from their trips, they'll show up here." Empty itineraries mirrors it. Deactivated/blocked handle from a stale link → generic "This profile isn't available". Long names ellipsize at 1 line; bios clamp at 2. Offline: header renders from cache, lists show inline Retry.
Motion — M1–M5 (all live in the frames)
M1 · FOLLOW TOGGLE
Press: scale 0.96, 120ms ease. Fill/label crossfade 180ms ease (terracotta → outline). Check icon fades in with the label swap — no bounce, no confetti. Revert-on-failure uses the same 180ms crossfade back.
M2 · TAB SWITCH
Label color + 3px bar: 160ms ease. Incoming panel: fade + 8px rise, 200ms cubic-bezier(.2,0,0,1). Outgoing panel is removed, not animated — content never overlaps. Trip section expand/collapse reuses the same curve at 180ms; chevron rotates 180° in 200ms.
M3 · SUGGESTIONS DROPDOWN
Panel: fade + 6px drop-in, 160ms cubic-bezier(.2,0,0,1) on first paint of a query's results. People rows stagger 30ms each (cap 3 → max 90ms). Group re-renders on later keystrokes swap in place with no animation — motion marks arrival, not churn.
M4 · RESULTS CASCADE
On query commit, rows fade + 6px rise, 200ms ease, 40ms stagger, capped at the first 8 rows (later pages append without animation). Same cascade grammar as Travelers M6.
M5 · REDUCE MOTION
prefers-reduced-motion: all translates and staggers drop; every state change becomes a plain 120ms opacity swap. Chevron rotation and press-scale are removed entirely. Nothing in this spec conveys meaning through motion alone.
