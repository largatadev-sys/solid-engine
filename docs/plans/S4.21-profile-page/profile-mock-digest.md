# S4.21 — profile mock digest *(source: `Profile.dc.html`, Claude Design project `34e84995-d099-46dd-a784-3b762a09d6f4`; archived 1:1 in `mock-render.html`)*

The mock is the **design baseline** (CLAUDE.md mock rule). Two frames — 2a Diary tab, 2b Itineraries tab — identical above the tab row. This digest records the load-bearing values read from the mock's own markup, so the build does not re-derive the export.

The frame is 393px wide. `Figtree` renders as **Inter**, `Outfit` renders as **Inter** — the house mapping for every mock-derived surface (spec deviation 4). Status bar and home indicator are phone chrome, not built UI (deviation 5).

## Values the mock draws that the build must NOT copy literally

Per the spec's decision 4, every one of these is generated by the stub module and re-rolled per render; the mock's numbers are illustration only.

| Mock literal | Ships as |
|---|---|
| Followers `142`, Following `89` | random int 1–100 each |
| `14 likes`, `28 likes`, `45 likes`, `32 likes` | random int 1–100 per postcard |
| `4.9`, `4.7`, `4.8` | random 1.0–5.0, one decimal |
| `₱22,000 / person` etc. | random ₱10,000–20,000 in hundreds; `/ person` text ships as drawn |
| Published `3`, Trips `8` | **real counts** — these two are backed |

## Truncation risks flagged for the phone-frame check (AC 8)

Both title rows are `space-between` with a `flex:none` trailing badge and a title that will lose the fight for the last pixels — the S3.1 `flexShrink` class. The postcard title/`Day 1 · 6:12 PM` pair and the card title/`PUBLISHED` pair are the two to screenshot on the emulator.
