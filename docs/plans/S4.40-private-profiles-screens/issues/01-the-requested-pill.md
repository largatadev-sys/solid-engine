# 01 — The Requested pill on the profile

**What to build:** the tracer bullet. A traveler taps Follow on a private profile and the pill reads **Requested** at once; a second tap cancels, confirm-free; the server's answer reconciles whatever it says; a refused request reverts the pill and names the traveler in a toast. Everything downstream reads through the types, the copy module and the three-state machine this ticket adds (spec decisions 6, 17, 18; canvas frames 1a/1b, contract C1, motion M1).

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] **Types, additive:** `profileVisibility` on the me response; an optional `profileVisibility` on the profile patch request; `visibility` and `viewerRelation` on the public profile response; the follow call's `{ state }` answer; the follow-request card (`traveler`, `requestedAt`); and the `PROFILE_PRIVATE` code, branched on by **code**, never by status. The wire's `followedByViewer` stays where it is and gains no new reader.
- [ ] **One copy module** for every string on the canvas's handoff card, byte-for-byte and plain ASCII, in a `.ts` module the screens and the Playwright specs both import (the S4.28 TSX-import trap). First-name substitutions ride the existing first-name helper. S4.37's strings stay where they live; this module holds only what S4.40 adds.
- [ ] **The follow-state machine widens** from a boolean to `none | requested | following`. The target's `visibility` is an input: a tap from `none` predicts `requested` on a private target and `following` on a public one, before the server answers; a tap from `requested` or `following` yields the one delete intent. In-flight taps are swallowed. Settling reconciles to the server's `state`, including the case where the prediction was wrong (predicted `requested`, the server says `following` because an edge already existed). Reverting restores the pre-tap state. The followers count moves only for the public case — a request changes no count. The existing follow-state Jest suite is the prior art and is extended for every transition.
- [ ] **The follow mutation returns the server's state** instead of `void`; cancel and unfollow are the same delete call. The public profile screen reads `viewerRelation` as the pill's opening state.
- [ ] **The third treatment on the profile header**, per C2 and the canvas: white fill, 1px hairline border, muted label, no glyph; height 40, radius 999, **no width change between states**; **M1** — fill, border and label crossfade 160ms across all three states, press scale 0.96 at 120ms, reverts reuse it; under Reduce Motion a 120ms opacity swap, no scale (the existing reduced-motion hook). The accessibility label names the state.
- [ ] **Toasts** in the S4.37 dark-pill grammar, 2.5s: "Couldn't send a request to @handle" and "Couldn't cancel the request" for a private target; S4.37's existing follow and unfollow toasts for a public one.
- [ ] **Playwright, web, against the preview container** — roles per the test-identity rule: **t1 = private owner** (flipped private through the API in setup, the private-profile API spec's shape, since the switch is ticket 03's), **t3 = stranger**. t3 opens t1's profile: the pill reads Follow → tap → Requested at once → the server's relation for t3 is `requested` (polled through the API) → tap → Follow → the server says `none`. A refused request (the follow route intercepted to answer 500) puts the pill back and shows the toast, the follow spec's "a refused follow puts the pill back" case as prior art. Every existing follow-spec walk on a public target stays green.
- [ ] **Interim, named:** until ticket 02 lands, a stranger on a private profile still sees the tabs, and the diary tab's read answers `PROFILE_PRIVATE` through today's retry state. Acceptable inside the branch; ticket 02 is next on the frontier.
- [ ] Process gates: the full Jest run before any push that adds a file under `src` (the changed-since blind spot); `npx playwright test --list` after adding the spec, the `Total:` line read.
