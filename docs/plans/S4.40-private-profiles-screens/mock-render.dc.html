The Public/Private audience chips are removed. One static 13px muted line replaces them; itinerary visibility is no longer a per-itinerary choice.
Contracts
C1 · PILL STATE MACHINE
States: none / requested / following. Tap on a private profile goes to Requested optimistically; tap on a public one goes to Following. A second tap cancels the request or unfollows, confirm-free. Failure reverts and toasts "Couldn't send a request to @handle" or "Couldn't cancel the request". Taps during an in-flight request are ignored.
C2 · APPROVE / DECLINE
Both remove the row optimistically. Failure restores it and toasts "Couldn't approve @handle" / "Couldn't decline". Decline has no confirm and is silent to the requester.
C3 · VISIBILITY SWITCH
Saves on flip, optimistic. Failure reverts with "Couldn't change your profile visibility". Private → public passes through the confirm in 3c; public → private has no confirm.
C4 · LIVE SURFACES
The requests list, the own followers list, and the own stats update without a refresh. The pill on other travelers' screens refreshes on focus.
Motion
M1 · PILL CROSSFADE
From the Follow canvas: fill, border and label crossfade ~160ms ease across all three states; press scale 0.96 at 120ms. Reverts reuse it.
M2 · LIST CASCADE
Requests and followers rows: fade + 6px rise, 200ms ease, 40ms stagger, first 8 rows.
M3 · ROW EXIT
Approve, Decline, Remove follower, and the Follow requests row on going public: the row fades + drops 6px over 200ms ease (M2 reversed, no stagger), then the list closes the gap. A failed request plays M2 on the restored row. Reaching zero rows swaps in the empty state with M2.
M4 · SHEET
Row sheet: scrim fades in 160ms ease; sheet slides up from the bottom edge 260ms cubic-bezier(.2,0,0,1). Dismiss or scrim tap reverses both at 200ms. Sheet rows press at scale 0.98.
M5 · CONFIRM DIALOG
Going-public and Remove confirms: scrim 160ms ease; card fades + scales 0.96 → 1 over 200ms cubic-bezier(.2,0,0,1). Cancel reverses at 160ms. Confirming dismisses the dialog first, then the affected row plays M3.
M6 · SWITCH + PRESS
Private-profile switch: track color 160ms ease, knob slides 160ms cubic-bezier(.2,0,0,1); a reverted save slides it back the same way. Every new control (Approve, Decline, kebab, dialog buttons, compact pill) presses at scale 0.96 over 120ms; hover/press fills 160ms.
REDUCE MOTION · NORMATIVE
Every state change becomes a 120ms opacity swap: no translates, no slides, no scale, no staggers, no press scale. Sheets and dialogs simply fade.
Not drawn, by decision
No Private or Follows-you chip on any header: the notice already says it. No published itineraries on a private profile a stranger or requester views (1a–1c). No counts or badges for requests anywhere. No private marks on search results, list rows, feed bylines or discovery cards. No privacy note in the postcard composer. No consent line on the Photo Dump. No Diary or Itineraries tabs on 1a–1c. No lock icon. The notice never says "This account is private".

DECISION LOG · CHANGES FROM THE BRIEF
1. No Private chip on any header (1a–1d, 2). The notice already says the profile is private; a chip duplicated it.
2. No Follows-you chip on 1d for the same reason; the chip anatomy is unused in this story.
3. Published itineraries are hidden from a private profile viewed by a stranger or requester (1a–1c). The notice is the last element on all three. Itineraries remain reachable by address and search.
4. Open question: the Account helper text still reads "Your published itineraries stay public." Kept verbatim; revisit if item 3 makes it misleading.
