Free-text locations become Google Maps links — read surfaces only
No form or picker changes. Every frame below is a read surface where an existing free-text place string gains a tap — Google Maps. One affordance vocabulary throughout; no pin glyphs are added to forms (the only pins drawn here are the feed/postcard tag chips, which already ship one).
The vocabulary — one rule everywhere
Rest: place text tinted workspaceColors.accent #EA580C, weight {{ linkWeight }}, no underline, no added glyph on plain-text links.
Pressed: ink darkens to #C2410C (travelerColors.accentDark); chips also swap their well to a deeper wash. No scale, no opacity.
Ellipsis: single line, tail-truncated. On split meta lines, numberOfLines lives on the outer Text (RN can't clamp a nested segment alone).
Glyphs: the tag chips' existing pin is the only glyph — no external-link cue anywhere. Plain text links stay glyph-free; tint alone is the affordance.
Dev shape (no schema change)
Every surface already carries the string: activity.place, card.place, entry.place, projection.destination.
New util mapsUrl(place) → google.com/maps/search/?api=1&query=… (URL-encoded free text), opened via an openInMaps.native/.web split (Linking.openURL / window.open '_blank') — the codebase's usual platform-split pattern; no Linking use exists yet.
Recommended: on workspace/published activity rows, append the trip destination to the query ("Big Lagoon Kayaking, El Nido") — bare free text is too ambiguous for Maps. Feed/postcard tags query their own string as-is.

Row anatomy
Middle row = pressed (orange outline is annotation only). Third row = time-only contrast: nothing tappable, meta stays fully muted.
The real dev cost: activityMetaLine() returns one joined string. It must return parts {clock, place} so the row renders <Text>clock • <Text onPress>place</Text></Text>. Separator " • " stays plain and belongs to the outer Text.
Hit target: the segment is 12px text — nested Text can't take hitSlop, so pressed feedback is ink-only and the acceptable target is the text run itself; do not wrap the whole meta line (mis-taps on the time would open Maps).
Clock format: drawn "7:00 AM" (unpadded) per the diary's postcardClock precedent — shipped formatTimeOfDay pads "07:00 AM". Unify on unpadded while splitting the line.
A11y: place segment gets accessibilityRole="link", label "Big Lagoon Kayaking, open in Google Maps".
